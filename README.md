# Patas & Lar 🐾

Site institucional fictício de uma ONG de resgate e adoção de animais, 
desenvolvido como projeto acadêmico da disciplina de Desenvolvimento 
Front-End (curso de ADS).

🔗 **[Ver site publicado]([https://seu-usuario.github.io/nome-do-repositorio/](https://camillatuzia.github.io/patas-e-lar-atv-academica/)**

## Sobre o projeto

A Patas & Lar é uma organização não-governamental (fictícia) que resgata 
animais em situação de rua, oferecendo atendimento veterinário, recuperação 
e abrigo temporário até a adoção definitiva. O projeto simula uma plataforma 
digital completa para captação de doações, voluntários e adotantes.

## Tecnologias utilizadas

- **HTML5** semântico (header, nav, main, section, article, footer, address)
- **CSS3**, incluindo:
  - Design System com variáveis customizadas (cores, tipografia, espaçamentos)
  - Suporte a modo claro/escuro
  - Layout responsivo com CSS Grid (12 colunas) e Flexbox
  - 5 breakpoints (mobile-first)
  - Componentes interativos sem JavaScript (menu hambúrguer, modal, toast) 
    via checkbox hack
  - Validação visual de formulários com pseudo-classes nativas (:valid, 
    :invalid, :focus)

## Estrutura de páginas

- `index.html` — apresentação da ONG, projetos em destaque e pets disponíveis
- `projetos.html` — projetos completos, formas de doação, voluntariado, 
  pets disponíveis e processo de adoção
- `cadastro.html` — formulários de doador e de interesse em adoção
